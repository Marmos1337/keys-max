# Дополнительная цепочка доверия MAX

`max-ca.pem` скопирован без изменения из пользовательского архива
`КОНТЕКСТ_ДЛЯ_ПРАВОК_0.2.0.zip / production-config/max-ca.pem`.
Это публичная цепочка CA, не приватный ключ и не токен. Источник и отпечатки
были указаны администратором в контексте; новая независимая проверка цепочки
на production-соединении при сборке 0.3.0 не проводилась.

Существующий проверенный файл на сервере и его настройки не заменяйте без
необходимости. `compose.ca.yaml` монтирует `./certs/max-ca.pem` только для чтения
и задаёт `NODE_EXTRA_CA_CERTS=/app/certs/max-ca.pem`. Включайте этот overlay также
при `max:check` / `max:register`, не только при запуске приложения.

Root: D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31
Sub: 21:55:78:50:36:C9:00:DB:B5:F1:BB:2A:15:69:C8:0C:55:59:5B:D6:BF:94:86:7A:29:BB:DD:BC:7D:88:A3:F2

Не отключайте TLS-проверку через NODE_TLS_REJECT_UNAUTHORIZED=0. Не расширяйте
системное доверие произвольными сертификатами. Для иной установки используйте
цепочку, проверенную её администратором. HTTPS самого сайта по-прежнему обслуживает NPM.
