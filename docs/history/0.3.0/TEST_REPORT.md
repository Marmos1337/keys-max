### Важное ограничение браузерного стенда

В данной среде обычная HTTP-навигация Chromium блокируется инфраструктурой
(`ERR_BLOCKED_BY_ADMINISTRATOR`). Поэтому использован режим `--embedded`:
реальные HTML/CSS/ES-модули рендерятся в DOM Chromium на about:blank, а запросы
через тестовый мост обращаются к настоящему локальному Node HTTP/SQLite.
Формы, события, загрузка тестовых файлов, изменения в БД и последующее
перечитывание действительно выполняются. Это не статический мок API.

Однако это НЕ полноценная проверка штатного сетевого контекста Mini App:
так не проверены WebView MAX, его lifecycle/cookies/CSP, клавиатура телефона,
конкретный Android/iPhone и действительное получение сообщений ботом.
HTTP security headers, cookie-атрибуты, Origin, подпись и ACL проверялись отдельно
серверными тестами. Safari/WebKit не запускались.

`fresh-start-result.json`: 8 дополнительных проверок на отдельной чистой копии,
без исходного .env и данных. Setup создал секреты только в временном каталоге,
повторный setup не перезаписал их. Поднят реальный localhost HTTP-сервер:
health 0.3.0, public legal pages и новые модули доступны; приватное состояние
без сеанса недоступно. Через API создана комнатная аренда, после штатной
остановки/старта сохранены квартира, комнаты, настройки и schema_version=3.
Временный каталог удалён, реальные секреты не включены в ZIP.

`preserved-source-checks.json` подтверждает побайтовое сохранение из пользовательского
current-source.zip: public/privacy.html, public/terms.html, public/legal.css.
Новый публичный маршрут отдаёт эти же байты без авторизации.

OpenAPI 3.1: 37 путей, 15 схем; все внутренние ссылки разрешаются, operationId
уникальны. Файлы сборки/исходников перечислены в SOURCE_MANIFEST.sha256.
Изменения относительно предоставленного current-source.zip — CHANGED_FILES.json.
