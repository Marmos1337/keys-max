# Проверка «Ключи» 0.3.1

Проверен локальный исходный проект на основе `keys-max-0.3.0.zip`. Реальные
пользовательские данные не использовались. Изменения касаются визуальной системы;
серверный код отличается только строками версии в health/config/startup.

## Автоматические тесты — 130 / 130

`npm run check`: синтаксис **41 JS/MJS-файла**, затем **130 тестов**, без ошибок,
пропусков и отмен. Из них 120 прежних тестов HTTP, данных, миграций, прав доступа,
аренды, общих счётчиков, регулярных начислений, подтверждений и сообщений бота;
10 новых проверок общих компонентов `tests/ui-components.test.mjs`.

Новые проверки: общий `type=button`, доступные имена действий-иконок, безопасные
подписи и ARIA у вкладок, единое семейство карточек/строк/статистики, повторное

## Что означает встроенный браузерный стенд

Обычная HTTP-навигация Chromium в данной среде запрещена инфраструктурой
(`ERR_BLOCKED_BY_ADMINISTRATOR`). Использован `--embedded`: реальные HTML/CSS/
ES-модули выполняются в DOM Chromium на about:blank; тестовый Python-мост
направляет действия на настоящий Node HTTP/SQLite. Это **не статическая имитация
API**, но также **не настоящий MAX WebView**.

Так не проверяются браузерный сетевой контекст, его cookies/CSP/lifecycle,
экранная клавиатура телефона, доставка сообщений MAX и поведение конкретного
Android/iPhone. HTTP-права и обработка запросов проверены отдельно серверными
тестами. Safari/WebKit, Windows/macOS, Docker-сборка и действующий сайт/NPM
в этой среде не проверялись. Версия Node в прогонах: 22.16.0, ОС: Linux.

## Воспроизведение

Без сторонних runtime-зависимостей:

```sh
npm run check
python tests/fresh_start.py --output test-results/fresh
```

Для браузерных тестов нужны Python, Playwright и Chromium. В обычной среде
запускайте без `--embedded`, чтобы проверять нативную HTTP-навигацию. Например:

```sh
python tests/browser_smoke.py --output test-results/smoke
python tests/browser_feedback.py --output test-results/feedback
python tests/browser_revision_v3.py --output test-results/revision
python tests/browser_visual_system.py --output test-results/visual
python tests/browser_legal.py --output test-results/legal
```

В этой среде добавлялись `--embedded --chromium /usr/bin/chromium`.
Тесты создают только временные демо-базы, не подключаются к production.

## Сохранение исходной системы

`ui-source-preservation.json` сравнивает исходники с архивом 0.3.0: бизнес-модули,
бот, настройки запуска, сертификат и оригинальные изображения сохранены побайтово;
в `server/http.mjs`, `server/index.mjs`, `scripts/backup.mjs` изменена только
строка версии. Тексты `<section>` публичных документов совпадают. Полные отличия —
`CHANGED_FILES.json`; контрольные суммы — `SOURCE_MANIFEST.sha256`.

Обновление на сервер не выполнялось. Приёмка в MAX после выкладки обязательна:
`ОБНОВЛЕНИЕ.md` и `ПРОВЕРКА_ДЛЯ_ЗАКАЗЧИКА.md`.
