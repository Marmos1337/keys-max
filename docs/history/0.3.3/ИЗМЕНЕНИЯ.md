# 0.3.3 — единая визуальная система

Основа: `keys-max-0.3.0.zip`. Бизнес-логика и схема SQLite 3 сохранены.

- Новый `public/ui.js`: общие поверхности, строки, статистика, быстрые действия,
  навигационные строки и одинаковые pill-переключатели.
- Общие семантические цвета и токены вместо конфликтующих поздних CSS-правил.
- Кнопки: единая форма и иерархия, мягкие вторичные действия без обводок.
- Боковое меню, компактная навигация, правильная подсветка родительского раздела.
- Общие стили комнат/участников, счётчиков, начислений и подробностей записей.
- Формы, даты, селекты, загрузки, профиль, уведомления и диалоги согласований.
- Светлая/тёмная темы, focus-visible, reduced-motion, прокрутка узких вкладок.
- Публичные юридические страницы: только оформление, тексты разделов сохранены.
- 10 новых тестов общих UI-компонентов и отдельные браузерные visual/public suites.

В сервере и backup-скрипте обновлены только строки версии. API и правила данных
не менялись. Подробности сохранения файлов — docs/ui-source-preservation.json.

# 0.3.0 — правки по совместным голосовым и уточнению аренды

Основа — актуальный `current-source.zip` из контекста пользователя.

- Квартира / комнаты: отдельные rental_units, группы lease_members на каждом объекте,
  независимые аренды, запрет пересечения whole/rooms, сохранение старых аренд.
- Совместная оплата: несколько частичных claims, автор и сумма каждого перевода,
  раздельное подтверждение/отказ, защита от повторов и превышения остатка.
- Настраиваемые приборы, 1/2/3 тарифа, произвольные названия и повторные типы,
  общие и локальные приборы, архив/восстановление/отключение. История без утечки
  документов между комнатами. Никакой фиктивной отправки поставщику.
- Регулярные платежи: флажок начисления, отдельный список правил, будущие изменения,
  пауза/возобновление/удаление, генерация заранее, короткие месяцы и идемпотентность.
- Приглашение через Bot с явным подтверждением. Персональные одноразовые ссылки.
- Уведомления с автором/содержанием/контекстом, HTML-экранирование, лимит текста;
  кнопки на обсуждение/запись/счётчики/аренду. Хост диплинка настраивается.
- Ремонт закрывает автор-арендатор после отметки собственника. Ожидающие подтверждения
  отделены от решённых. Групповые согласования посещений/условий/завершения.
- Темы и правильный логотип, Android-отступы, перенос Add в раздел квартиры,
  единая история, спокойная типографика договора, русский ввод дат и месяцев.
- Сохранились функции 0.2: редактирование квартир и обложек, права на изображения,
  оригинальные бренд-файлы, покупки/компенсации, документы, экспорт и профиль.
- Публичные страницы из пользовательского кода сохранены побайтно; явные маршруты.
- Добавлен NPM overlay из production-контекста, CA bundle от администратора,
  настройка MAX_DEEPLINK_BASE; приёмка и инструкция миграции под существующий том.
- Реальные fixtures миграций v1/v2, закрытие SQLite при ошибке и повторяемая очистка
  временных каталогов. Исправление нацелено также на Windows EPERM; прогон выполнен Linux.

Контроль: 120 серверных тестов, 8+7+9 групп браузерных DOM/HTTP-проверок.
Детали и ограничения — docs/TEST_REPORT.md. Перед production: ОБНОВЛЕНИЕ.md.
