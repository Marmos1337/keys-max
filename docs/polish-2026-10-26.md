# Ключи 0.6.1 — design polish, 2026-10-26

Base: main fdbf2e0 (0.6.0 co-owners + Artegra). Reference: Медиатека «Облако» tokens
(4/8 spacing, 44 px targets, pill controls, radii 12/20/26, Inter + Artegra for h1).

How it was checked: `tests/telegram-local/polish_shots.py` walks every role (owner,
co-owner, tenant, room tenant, MAX tenant, newcomer) through all screens, tabs, sheets,
toasts, boot/error states, a pressed state and mid-animation frames at 320/375/390/430/768,
light and dark (data: `seed-rich.mjs` + `seed-polish.mjs`). Each frame is audited in the
page: horizontal overflow, cut text, cut select values, Russian plural agreement and
abbreviations, targets under 44 px, WCAG AA contrast, type under 12 px, gaps off the
4 px grid or zero gaps between blocks.

Audit of fdbf2e0 at 375 light: 872 findings (325 tiny type, 273 small targets, 194 off-grid
gaps, 20 low contrast, 19 cut select values, 31 abbreviations, 3 plural errors, 7 cut texts).
After: 0 at every width and theme (tab labels at 10–11 px are a platform exception).

## Found → fixed

### Copy, grammar, plurals
- [x] «1 арендаторов», «2 жильц.», «14 дн.», «2 комн.», «действует 7 дней» hard-coded → one
  `plural()/count()/days()` helper in `utils.js` (numbers glued to their noun with a no-break space).
- [x] Same people called «арендаторы» in the card and «жильцы» in the section → «жильцы» inside the
  apartment, «арендатор» only for the cabinet/role.
- [x] Tenant home said «Твоя квартира», the rest of the app says «вы» → «Ваша квартира».
- [x] Guide told tenants «Фото необязательны» although readings need a photo since 0.4.3 → fixed.
- [x] «Ссылка для «Маша»» → «Ссылка «Маша»»; link statuses read as one word set:
  Не открыта / Открыта / Принята / Истекла / Отозвана (no «Открыл(а)», «Ждёт»).
- [x] Gendered stubs «принял(а)», «убрал(а)», «вышел(ла)», «не подтвердил(а)», «присоединился» in
  notifications/history → neutral sentences.
- [x] Notifications: «…2026 г..» double dots, «65 000,00 ₽», line breaks lost in the list → fixed
  (server text + `white-space: pre-line`).
- [x] Request filter «Ждут подтверждения» vs badge «Ждёт арендатора» vs status «На проверке» → «На проверке» everywhere.
- [x] Stat «Квартир 1» → «Квартира/Квартиры»; «Подтверждено за месяц» cut at 320 → «Получено за месяц».
- [x] Dates without the trailing «г.»; day and month never split across lines.
- [x] «Создано … · версия 1» (technical) → «Создано …», plus «изменено …» when changed.
- [x] Bot hint pointed to «Квартира → Совладельцы» → «Собственники».

### Counters and labels
- [x] «Совладельцы 2» counted the main owner → section «Собственники» with the count of all owners
  (main + co-owners), same word the tenant sees; role in the row («Главный владелец»,
  «Совладелец · с …»), no duplicate chips; chips stay only for link statuses.
- [x] Counts sit next to the section title, not flush right.

### Truncation and layout
- [x] Tab strip «Обзор · Договор · … Ист» cut at the edge → horizontal scroller with edge fades that
  appear only on the hidden side, the active tab glides into view with a peek of its neighbour
  (also on filters and the apartment pills).
- [x] Lease selector «Квартира целиком · 1 жильц. · 1 сентября 2…» → a two-line row: what is let /
  «2 жильца · до 31 августа 2027», count of periods with a chevron; the native picker opens from the
  whole row; options read «Квартира целиком — 2 жильца, с 1 сентября 2026».
- [x] Event row on the tenant home broke into «Визи/т/собс/твен/ника» at 320 → icon · text with its
  status under it · chevron.
- [x] Quick tiles «Сообщить / о / проблеме» in three lines → icon above, two lines of text; 4 in a row on wide screens.
- [x] Two-button rows wrapping labels inside buttons («Добавить / счётчик») → labels never wrap,
  buttons take a full line each when they do not fit.
- [x] Owner overview: three stacked secondary buttons → lease actions in one grouped list
  (Покупки with «1 покупка ждёт решения», Посещения with the nearest date, Новые условия, Заявка).
- [x] Apartment-level blocks after lease-level ones: card → Жильцы → lease list → Что сдаётся → Собственники → Удаление.
- [x] Facts card: long single column → pairs (Плата/Депозит, Оплата до/Показания до), long values full width;
  repeated «Квартира целиком» title removed.
- [x] Record meta «Квартира на Лесной · Квартира целиком · …» → place only when it adds information.
- [x] «Открыть аренду» on the lease being viewed → «Открыта сейчас».
- [x] Page heading: subtitle squeezed by the button, 180 px phantom gap → words on the full width, actions below.
- [x] Detail actions inside an extra frame, two black primaries → no frame, one primary.
- [x] Tenant meter row: unit repeated above and beside the input, «Стартовое значение не записано» shown
  to tenants → unit only beside the input, «Предыдущих показаний нет».
- [x] Link box in a typewriter font → text face; disclosure got a turning chevron.
- [x] Role cards with forced line breaks («Я / собственник») → natural wrapping.
- [x] Error card touched the screen edges on phones → 16 px gutters.
- [x] Overdue bills were shown as «К оплате» → «Просрочен» badge, red payment card «Платёж просрочен / Срок был …».

### Spacing, type, targets, contrast
- [x] Gaps 14/18/22/26 px and margins from three layers → page blocks 16, sections 32, title→content 24,
  inside sections 12, form fields 16, notices 16.
- [x] Badges, record meta, stat labels, timestamps, units at 10–11 px → 12 px minimum (tab bar 11 px, 10 px under 360 px).
- [x] Record meta at 3.26:1 → muted token (AA); guide step numbers 4.46:1 → text colour.
- [x] Top bar buttons 40, tabs 38, «Все» 40, apartment filter select 26 px tall → 44 px.

### Motion
- [x] Changing a tab replayed the whole page entrance (hero and strip jumped) → only the content under the
  strip fades up, the selected pill settles in place; lists stagger.
- [x] Toast covered the open sheet → drops from the top while a sheet is open.
- [x] Transform/opacity only; `prefers-reduced-motion` turns all of it off.

## Not changed on purpose
- «Передал наличными» / «Получил» / «Не получил» — the owner's own words for the cash flow.
- History titles already stored in the database («Договор аренды: создано») stay as written.
