# Источники и происхождение материалов

## Пользовательские материалы

Архитектура ролей «Арендатор» и «Собственник», описание продукта «Ключи» и восемь
экранов, приложенные пользователем в этом чате. Из макетов использована общая
визуальная система и вырезаны иллюстративные фрагменты: welcome, интерьер,
изображения карточек ролей, три фото проблем и растровый wordmark.

Шрифты из системы/контейнера не копировались и не включены в архив. Интерфейс
использует системный стек. SVG интерфейсных иконок нарисованы кодом.
Персонажи/имена/суммы/даты в демо — вымышленные данные. Адреса из референса
используются только как демонстрационная подпись, не сведения о реальной аренде.

Права на предоставленные иллюстрации автоматически не устанавливались.
Перед публичным распространением подтвердите право их использования либо замените
на свои в `public/art/`. Фотографии и wordmark не выдаются за официальные активы MAX.
Код приложения можно свободно изменять в рамках вашего проекта; правовой статус
чужих бренд-активов/изображений этим утверждением не меняется.

Трек «Умный город.pdf», предоставленный пользователем: жилищные процессы,
работающий сценарий в MAX, явное обозначение тестовых данных, Docker и документация.
Собственная продуктовая реализация шире одного сценария и не считается автоматической
гарантией баллов, юридического соответствия или прохождения модерации платформы.

## Официальная техническая документация

Проверено 22 сентября 2026. Документация может изменяться; перед публикацией
сверьте её снова. В коде не используются частные API и клиентские токены MAX.

- Обзор API, актуальный домен, заголовок Authorization, доверенная цепочка:
  https://dev.max.ru/docs-api
- Проверка подписи MAX / WebAppData:
  https://dev.max.ru/docs/webapps/validation
- Bridge, initData, нативное скачивание и способы взаимодействия:
  https://dev.max.ru/docs/webapps/bridge
- Подключение Mini App и startapp:
  https://dev.max.ru/docs/webapps/introduction
- Подписка webhook, secret и стандартный HTTPS-порт:
  https://dev.max.ru/docs-api/methods/POST/subscriptions
- Отправка сообщений:
  https://dev.max.ru/docs-api/methods/POST/messages
- Ответ на callback:
  https://dev.max.ru/docs-api/methods/POST/answers
- Клавиатуры:
  https://dev.max.ru/docs-api/use-cases/sending-messages/keyboard
- Типы событий:
  https://dev.max.ru/docs-api/objects/Update
- Ветки Node.js и сроки поддержки:
  https://nodejs.org/en/about/previous-releases

Не являются фактами из документации MAX: наши состояния заявок, схема БД,
финансовый учёт, ограничения ролей и бизнес-правила. Это проектные решения
конкретно для этой реализации «Ключей».

Основа — current-source.zip из КОНТЕКСТ_ДЛЯ_ПРАВОК_0.2.0.zip пользователя, включая
согласованные public/privacy.html, terms.html и legal.css. Их SHA-256 сверены с
